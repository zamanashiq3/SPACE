# SPACE — Spatial Phase, Activity and Current Estimation

Analysis pipeline for anatomically registered, spike-sorting-free analysis of 4,096-channel
HD-MEA recordings (3Brain BioCAM, 64 × 64 grid) from acute mouse brain slices. This repository
contains every processing and analysis step reported in the accompanying manuscript:

> *SPACE: A mesoscale computational framework for characterizing network coherence and
> pharmacological profiling in high-density MEAs* (2026, in review).

From raw `.brw` recordings it produces the tissue-contact mask, the 2 ms-smoothed LFP and planar
CSD arrays, event-aligned ROI epochs, and all SPACE features (LFP amplitude/energy/slope,
participation-ratio complexity, regional CSD activity and source–sink balance, lag-1
autocorrelation / sample entropy / mean-crossing rate, Hilbert phase and Kuramoto synchrony,
phase-gradient directionality, Welch/wavelet spectra and 1/f exponent, neuronal avalanches,
inter-regional CSD coupling, drug-normalized spatial maps, stereotypy) together with the
SPACE-versus-conventional benchmark (ROC, scalability, feature sensitivity). The companion
repository **[lfp-csd-explorer](../lfp-csd-explorer)** renders the CSD/LFP maps, kymographs
and movies used for the descriptive figure panels.

Raw `.brw` recordings are **not** distributed (file sizes); a synthetic example dataset that
exercises every script is generated by `examples/make_synthetic_example.py`, and the full
dataset is available from the corresponding author on reasonable request.

**[METHODS_TO_CODE.md](METHODS_TO_CODE.md)** maps every paragraph of the manuscript Methods to
the script, function and parameter that implements it — start there if you are checking the
paper against the code.

## Pipeline overview

```
data/raw_brw/*.brw                 data/slice_photos/*.{png,bmp,tif}
       │                                     │
       │                                     ▼
       │                     preprocessing/tissue_registration_mask.py   (homography, Otsu,
       │                                     │                            30 % coverage → Ω)
       ▼                                     ▼
preprocessing/brw_to_2ms_h5.py  ◄──  data/masks/<slice>__contact_mask_64x64.npy
  notch 60 Hz (Q 30) → Butterworth 1–350 Hz (sosfilt, causal, 4000-sample chunks)
  → 2 ms moving average (10 kHz kept) → Gaussian σ=1 → 5-point Laplacian CSD
       │
       ▼
data/processed_2ms/<group>/<slice>_<condition>_2ms.h5   (/lfp/ts_2ms_full, /csd/ts_2ms_full, /mask)
       │
       ├── core/roi_lfp_csd_metrics.py ──► data/roi_definitions/<slice>_roi_definitions.csv  (6 × 4×4 ROIs)
       │
       ├── preprocessing/extract_event_epochs.py ──► data/event_traces/<group>/<ROI>/<cond>/event_k_*/   (3 events, 500 Hz)
       │        │
       │        ├── core/psd_wavelet_metrics.py          LFP amplitude/energy/complexity, balance index,
       │        │                                         Welch bands, specparam 1/f, Morlet wavelet      (Fig. 2, 4, 6C–D)
       │        ├── core/electrode_connectivity.py       within-ROI 16×16 and 96-node inter-regional coupling (Fig. 3G–H, 7C–D)
       │        ├── core/ctx_hippo_avalanche_kuramoto_compare.py  regional Kuramoto R / MPV / PLV, ROI avalanches (Fig. 5H–I, Suppl. 3)
       │        └── benchmark/roc_scalability_sensitivity.py       ROC, scalability, feature sensitivity        (Suppl. 7)
       │
       ├── core/regional_csd_dynamics.py     regional |CSD|, total current, RAI, BI(t), lag-1 AC, SampEn, MCR (Fig. 2F–M)
       ├── core/roi_lfp_csd_metrics.py       maps at 0/250/500 ms, raw traces, kymographs, ROI corr matrices  (Fig. 2A,C; 3A–G)
       ├── core/roi_phase_gradient_pgd.py    generalized phase, gradient vectors, PGD, propagation direction (Fig. 5A–C, 7E)
       ├── core/phase_kuramoto.py            whole-slice Hilbert phase, Kuramoto R(t), Φ(t), MPV, coherence map (Fig. 5D–G, 7F–G)
       ├── core/avalanche_statistics.py      whole-slice streaming nLFP avalanches + power-law fits           (Suppl. 3)
       ├── core/drug_lfp_zscore_maps.py      drug-normalized LFP maps, network-state deviation               (Fig. 6A–B)
       ├── core/condition_stereotypy.py      5 × 5 condition correlation, stereotypy index                   (Fig. 7B)
       ├── benchmark/welch_psd_recordings.py recording-level Welch PSD tables (conventional comparison)
       ├── benchmark/spectral_sensitivity_bh_fdr.py  pairwise Mann–Whitney/Cliff's δ/BH-FDR, SPACE vs PSD (supporting)
       └── utils/pick_representative_recording.py    objective choice of representative recording (column-artefact z)
```

Inferential statistics (Welch's *t*-tests, Benjamini–Hochberg, linear mixed-effects models)
were run in GraphPad Prism on the **animal-level tables** written by these scripts
(`animal_level.csv`, `network_state_deviation.csv`, `stereotypy_index.csv`, and the
per-ROI summary CSVs); the scripts themselves report descriptive and event-level statistics only.

## Installation

```bash
git clone <this repo> && cd SPACE
python -m venv .venv && source .venv/bin/activate      # Python >= 3.10
pip install -r requirements.txt                        # or requirements-pinned.txt for the exact versions used
```

`powerlaw`, `specparam`, `networkx`, `statsmodels` and `umap-learn` are optional: each script
that uses one falls back to a documented alternative (discrete MLE power-law fit, log–log 1/f fit,
skipped graph metrics, numpy autocorrelation) when it is missing. `ffmpeg` is only needed for MP4
output in the companion visualizer.

## Quick start on the synthetic example

```bash
bash examples/run_example.sh            # ~25 min on 2 cores; writes data/example_synthetic/
```

The script generates two synthetic slices (CTL, 5xFAD; 4-AP and AFDX conditions) and runs every
module in order. Outputs land in `data/example_synthetic/results/<module>/` and can be compared
with the manuscript's figure panels for format. The synthetic signal is a travelling Gaussian
deflection plus oscillation and 1/f noise and carries no biological meaning.

## Running on your own recordings

1. `preprocessing/tissue_registration_mask.py --image photo.png --out data/masks` (click the four
   corners of the array) → `data/masks/<slice>__contact_mask_64x64.npy`.
2. `preprocessing/brw_to_2ms_h5.py --brw_dir data/raw_brw --mask data/masks/<slice>__contact_mask_64x64.npy --out data/processed_2ms/<group>`.
   Recording file names must contain the condition token (`4ap`, `afdx`, `bic`, `cnqx`, `ml297`)
   and the slice id used in the mask file name.
3. `core/roi_lfp_csd_metrics.py` (interactive TIFF-aligned picker, once per slice) →
   `data/roi_definitions/<slice>_roi_definitions.csv`; or write the CSV by hand
   (`roi_index,roi_name,r0,r1,c0,c1`, Python slice bounds, 4 × 4 boxes, names M1 M2 S1 CA1 CA3 DG).
4. `preprocessing/extract_event_epochs.py` → `data/event_traces/`.
5. Run the `core/` and `benchmark/` scripts; every script has `--help`, and every path default is
   under `data/` (see `data/README.md` for the folder schema).

## Conventions

- Electrode flat index = `row * 64 + col`; ROI electrodes are row-major within the 4 × 4 box.
- CSD sign: negative = sink, positive = source; units are arbitrary (σ_c = 1; the stored CSD is the
  Gaussian-smoothed five-point Laplacian divided by the electrode pitch squared, a constant that
  does not affect any comparison).
- Analysis window 0–250 ms, baseline −50–0 ms (inclusive) unless the Methods state otherwise;
  each electrode trace is baseline-corrected by its baseline median.
- Pooled regions: Ctx = {M1, M2, S1}, Hippo = {CA1, CA3, DG}; the animal (slice) is the unit, so
  ROI values are averaged within region per animal before any inferential test.
